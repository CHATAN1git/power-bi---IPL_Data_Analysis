# 🏏 IPL Data Analysis Dashboard - Power BI Project

Welcome to my IPL (Indian Premier League) Data Analysis project!  
This interactive dashboard is built using **Power BI** and showcases deep insights from IPL match data across multiple seasons.

## 📌 Project Objective
The main goal of this project is to analyze historical IPL data to:
- Understand team and player performances
- Identify match-winning factors
- Discover trends across seasons
- Present the insights in an interactive and visual format using Power BI

## 📊 Features of the Dashboard
- 🏆 **Team Performance Overview** – Wins, losses, and trends by team
- 🎯 **Top Players** – Highest run-scorers, wicket-takers, and consistent performers
- 🗓️ **Season-wise Insights** – Match results, toss decisions, and venue impact
- 📍 **Interactive Filters** – Slice data by year, team, venue, and player
- 📈 **KPI Cards & Custom DAX Measures** – For quick glance performance metrics

## 📁 Files Included
